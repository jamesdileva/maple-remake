# Game Design

## 1. Game Pillars

### Immediate Power
The player gets meaningful, screen-clearing abilities from level 1.

### High Density
Maps contain many mobs.

### Generous Progression
Players advance quickly and receive frequent rewards.

### Simple Systems
The game avoids the MMO tendency to accumulate dozens of interconnected systems.

### No Bad Builds
Skill points can be reset freely and ultimately every ability can be maxed.

### Readable Bosses
Bosses communicate their mechanics visually.

### Stylish Classes
Each class has a strong fantasy and visual identity.

### Dark Fairytale World
The world is visually appealing but increasingly unsettling.

## 2. MVP Player Journey

```text
Create character
→ learn movement
→ learn basic attack
→ unlock FMA immediately
→ kill dense mob packs
→ collect/vacuum loot
→ unlock class abilities
→ reach ~level 20
→ class advancement
→ experience dramatic new abilities
→ progress through darker regions
→ fight bosses
→ reach continent finale
```

## 3. Classes

### Mage
Elemental destruction.

### Warrior
Sword-and-shield juggernaut.

### Archer
Bow/crossbow ranged specialist.

### Assassin
Shadow executioner.

## 4. Progression

Target:
- level 1–40/50
- advancement around level 20
- 10–20 hour first continent

All abilities eventually max.

Skill reset:
- free
- unlimited

No permanent mistakes.

## 5. Equipment

Slots:
- weapon
- top
- bottom
- helmet

Equipment is normalized and readable.

If an item says:
> +100 Power

it provides exactly that value.

Avoid:
- random stat soup
- hidden item quality math
- mandatory external databases

## 6. Loot

Auto-loot/vacuum is always available.

Loot should be frequent enough that the player feels rewarded without stopping the combat loop.

Bosses can provide:
- stronger equipment
- valuable currency
- unique visual rewards

But no mandatory 100-hour chase.

## 7. Currency

One primary currency for MVP.

NPC shops provide:
- useful consumables
- equipment
- basic services

Player trading is deferred until multiplayer.

## 8. World

MVP contains one compact continent.

Potential progression:

```text
Bright starting town
→ cheerful outskirts
→ dense forest
→ unsettling forest
→ corrupted area
→ mine/ruins
→ haunted structure
→ final region
→ continent boss
```

The world should become darker without becoming relentlessly grim.

## 9. Tone

Desired feeling:

> "This world looks almost like a cheerful fantasy game, but something is deeply wrong."

Avoid:
- excessive gore
- childish presentation
- generic dark fantasy
- edgy horror for its own sake

Use:
- unsettling silhouettes
- strange NPC behavior
- abandoned locations
- distorted creatures
- cheerful environments with wrong details
- horror through implication

## 10. Traversal

Compact platform maps.

Movement:
- walking
- running
- jumping
- class-specific mobility

Controller support is a day-one requirement. The game must be fully playable and fully navigable (menus, HUD, debug tools) with either keyboard/mouse or a controller.

Ropes/ladders are not required.

Normal mobs do not require elaborate traversal because FMA abilities dominate clearing.

Bosses make movement important again.

## 11. Party

Future:
- 4 players

The four classes are intentionally designed so that a complete party feels valuable.

Four unique classes receive the full unique-class XP multiplier.

Duplicate classes do not stack the same unique-class XP benefit repeatedly.

## 12. Multiplayer

Not MVP.

The first version is single-player.

The gameplay systems are designed so multiplayer can be added later.

## 13. What the Game Does NOT Need

For MVP, avoid:

- crafting
- professions
- pets
- guilds
- PvP
- auction house
- complex quests
- daily missions
- battle pass
- multiple currencies
- accessories
- random affixes
- complicated talent trees
- energy/stamina
- forced dailies
- loot boxes
- mandatory grinding
- external guides

## 14. Player Guidance

The game should teach through:
- short tutorials
- NPC dialogue
- ability demonstrations
- visual indicators
- simple tooltips

If a mechanic is important, the game explains it.

## 15. Design Success Test

A new player should be able to answer:

- What am I supposed to do?
- What does this ability do?
- Is this equipment better?
- Why did I die?
- How do I beat this boss?

without opening a browser.
